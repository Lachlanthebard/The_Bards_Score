# Bard's Score — Quick Reference

**Score:** OK → pitch → OK → duration → OK to insert. Left/Right selects a note. Up/Down changes pitch. Short Back deletes; hold Back exits. Hold OK opens Score tools.

**Score tools:** Up/Down to navigate, OK to choose, Back to close. The menu wraps from top to bottom.

**Chords:** Select a pitched note → Add chord tone → choose pitch → OK. Four pitches maximum. Remove chord tone removes the last added pitch.

**Voices:** Switch voice changes the active part. Combined/solo view toggles the display. Play both voices approximates simultaneous playback.

**Notation:** Add rest; set time and key; slur/tie start and end; staccato, accent, fermata.

**Playback:** Play score, play from here, preview note, set tempo. Back stops playback.

**Files:** Save score → `apps_data/bards_score/melody.bsc`. Export XML → `apps_data/bards_score/melody.musicxml`. Both overwrite existing files; back them up.

**Help:** Score tools → About / Help; Up/Down to change pages, Back to return.
